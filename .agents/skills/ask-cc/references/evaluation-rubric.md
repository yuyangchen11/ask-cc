# Evaluation Rubric

Use this checklist before returning an interview answer.

## Must Pass

- Does the answer directly answer the question?
- Can the candidate say it in 1 to 2 minutes?
- Does it explain the business background?
- Does it include the candidate's personal responsibility?
- Does it mention at least one concrete action?
- Does it include a metric or result when available?
- Does it avoid sounding like a written report?
- Does it avoid overclaiming ownership?

## Red Flags

- The answer only repeats the resume.
- The answer uses abstract labels without examples.
- The answer includes numbers without explaining口径 when challenged.
- The answer claims a causal result that cannot be defended.
- The answer ignores users, scenarios, costs or constraints.
- The answer sounds like generic AI copy.

## Improvement Moves

If an answer is too vague, add the specific user, scenario, action and metric.

If an answer is too long, keep the opening context and compress execution into three clear points.

If an answer sounds too formal, rewrite it in first person with phrases the candidate can actually say.

If an answer is risky, add a boundary such as "我参与的是其中..." or "这个结果更准确地说是团队项目上线后的表现".
